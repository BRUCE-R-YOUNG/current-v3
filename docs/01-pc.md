# 1. PCの準備

以下は pc フォルダをカレントディレクトリにして実行します。Python 3.11以降を推奨します。

## 受信だけ始める
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py init
.\.venv\Scripts\python.exe run.py dashboard --host 127.0.0.1 --port 8001
```

config/server.yaml が既にある場合、init は不要です。既存環境で python.exe の Permission denied が出た場合は、使用中のサーバーを止めてから環境を作成するか、別名の仮想環境を使用してください。稼働中の仮想環境を上書きしないでください。

ブラウザで http://127.0.0.1:8001/v3 を開きます。この起動プロセスを止めると受信も止まります。サーバー自体のPC起動時の自動起動は本手順では設定しません。

## アクセストークン
環境変数 SVL_EDGE_TOKEN が未設定なら、初回起動時に次のファイルへランダムなトークンを生成します。

```text
config/runtime/server/access-token.txt
```

この値をダッシュボードの認証入力に使い、Raspi側の SVL_EDGE_TOKEN にも設定します。これはTailscaleのログイン情報やauth keyとは別の、アプリのAPI用秘密鍵です。現在は受信だけでなく管理APIにも使う共通トークンなので、信頼する端末だけに配布してください。

紛失・漏えい時はPC停止後に新しいトークンを環境変数で設定して再起動し、Pi側も変更します。環境変数指定はファイルより優先されます。Git・メール・スクリーンショットへ掲載しないでください。

## 送信先プロジェクトを作成
ダッシュボードの受信側のプロジェクト作成機能を使って、例として elevator-a を作成します。Piの project_id と完全に一致させます。未知のプロジェクト宛の画像は404で拒否されます。受信だけで勝手にプロジェクトは作成しません。

次に [VPNの設定](02-tailscale.md) へ進みます。

## 受信API
|API|用途|
|---|---|
|GET /v3/status|キュー件数・最近の集計・状態・エラー|
|POST /v3/ingest|画像または集計イベントを受信|
|GET /v3/config|設定取得|
|PUT /v3/config|設定更新（実行中サービスがあると拒否）|
|POST /v3/services/{name}/start|PC処理開始|
|POST /v3/services/{name}/stop|停止要求|

HTML画面以外は Authorization: Bearer <トークン> が必要です。画像はJPEGをbase64にしてJSONで送ります。イベントIDの一致を応答で確認して初めてPi側で送信済みにします。同じID・同じ内容の再送は重複保存しません。上限は1リクエスト2MB、JPEG画像4メガピクセルです。
